# PT Ridig Sukses Berjaya

Website satu halaman untuk pusat papan digital dan jam sholat digital masjid (Pekanbaru, Riau).

## Isi halaman
- Hero dengan video latar, jam digital live (WIB), hitung mundur sholat, dan warna LED yang bisa diganti
- Katalog produk
- Simulasi running text LED (matriks titik, atur teks, warna, kecepatan, gaya)
- Kalkulator ukuran papan (modul P10 dan P5)
- Peta wilayah layanan Indonesia
- Portofolio foto dan desain, FAQ, form kontak ke WhatsApp

## Cara pakai
`index.html` berdiri sendiri: video, foto, dan logo sudah tersemat di dalamnya, jadi cukup dibuka langsung atau dipasang di GitHub Pages. Font dimuat dari Google Fonts.

Folder `assets/` berisi salinan video hero dan foto portofolio untuk kebutuhan edit ulang. Halaman tidak membacanya.

## Yang perlu diisi
Isi nomor WhatsApp admin di `index.html`, variabel `WA_NUMBER` (format `62812xxxxxxx`). Selama kosong, tombol WhatsApp belum berfungsi.
